# Lift Log

Hevy-style workout tracker. Web app, PWA, no server, data stays in the browser.
Ships with the Min-Max Phase 2 program (4-day). Spec: `../out/lift-log-spec.html`.

```
npm install
npm run dev      # http://127.0.0.1:5175
npm run build    # dist/ -> host on any HTTPS static host
```
On iPhone: open in Safari, Share, Add to Home Screen.
